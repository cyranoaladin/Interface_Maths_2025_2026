Entraînement NSI

Sujets blancs NSI classés

Choisir une famille, ouvrir un sujet, puis préparer une explication courte : vocabulaire, méthode, exemple au tableau.

Oral blanc

Simulation orale

Préparation courte, parole claire, tableau lisible. Le but est de montrer une méthode, même si le calcul est incomplet.

  • Lire le sujet, entourer les mots-clés, écrire les hypothèses.
  • Annoncer la méthode avant les calculs.
  • Si un calcul bloque, expliquer la suite prévue.
  • Répondre calmement aux questions de relance.
