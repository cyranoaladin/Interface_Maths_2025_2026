# Guidelines UI / UX

## Principes

- Interface sobre, pedagogique et lisible.
- Les dashboards doivent etre des surfaces de travail, pas des pages marketing.
- La securite affichee cote frontend doit toujours correspondre a une verification backend.

## Composants

- Cartes : resume, ressource, bilan, groupe.
- Tableaux : eleves, exercices, bilans.
- Boutons : action explicite, texte court, etat erreur/succes.
- Etats : chargement, vide, erreur, succes.

## Redaction

- Francais clair et direct.
- Messages d'erreur actionnables : "Acces refuse", "Bilan non disponible", "Connexion expiree".
- Ne pas exposer de details techniques ou de hashes dans l'interface.

## Responsive

- Sidebar empilee sous 980px.
- Les cartes doivent utiliser une grille fluide.
- Les tableaux doivent rester lisibles sur mobile, ou etre transformes en cartes dans une phase ulterieure.
